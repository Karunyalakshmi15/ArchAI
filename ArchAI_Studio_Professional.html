DATA PROFILE

What data is used?

No external dataset is connected.
Room dimensions are generated from the selected building profile and user-edited values. Area metrics are calculated from the current schematic, not learned from real building records.

Inputs used by the planner

  • Plot length and width (feet)
  • Building type, floors and target capacity
  • Selected rooms and their dimensions
  • Facing direction and construction rate

Calculated outputs

  • Site area = plot length × plot width
  • Room area = room length × room width
  • Utilization = planned room area ÷ site area
  • Indicative cost = built-up area × selected rate, plus contingency
LAYOUT METHOD

How a plan is generated

01
Read requirements

Collect site dimensions, building profile, floor count and requested spaces.

02
Prepare room program

Load the suggested rooms and apply enabled options and edited dimensions.

03
Pack and validate

Place room rectangles within the site and check boundaries and overlap constraints.

04
Render views

Draw the SVG plan and update the room schedule, analytics and cost estimate.

05
Compare snapshots

Save a named snapshot in this browser to compare alternative configurations.

Important limitations

This application is a conceptual planning aid, not an architectural approval, structural design, code-compliance assessment or construction drawing. Cost values are indicative assumptions and may differ from local quotations. Confirm dimensions, setbacks, ventilation, accessibility, fire safety and local regulations with a qualified professional before building.
